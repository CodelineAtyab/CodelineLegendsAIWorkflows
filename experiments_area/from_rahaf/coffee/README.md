# Coffee Order

This task helped me practice using *args and **kwargs in Python.

## *args

A good thing about *args is that I can add more positional arguments without changing the function.

A bad thing is that having too many arguments can make the function harder to understand.

## **kwargs

A good thing about **kwargs is that I can add extra keyword arguments when I need them.

A bad thing is that it can be harder to know which keyword arguments the function expects.
