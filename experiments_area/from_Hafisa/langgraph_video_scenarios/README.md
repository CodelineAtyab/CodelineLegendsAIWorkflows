# LangGraph Video Scenarios

These exercises recreate the five agent scenarios shown from 1:30:00 onward in
the [LangGraph course](https://www.youtube.com/watch?v=jGg_1h0qzaM).

Each script is intentionally deterministic and uses only local Python in place
of the course's LLM, tool, file, and vector-store services. The graph structure
and state transitions remain visible for practice.

Run a scenario from this directory with:

```text
uv run scenario_01_basic_agent.py
```
