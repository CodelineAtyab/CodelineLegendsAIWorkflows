# PythonSyntax

A practice file covering the core Python syntax from the foundations stage. Everything lives in
`main.py` as a short, runnable script so each concept can be read top to bottom and tried out
directly.

## What I practised

- **Variables and basic types** — integer, float, boolean, and string values, including a
  single-character string.
- **Conditionals** — an `if` / `elif` / `else` chain, using `len()` in the `elif` test.
- **Collections** — a list of team member names and a dictionary holding status information.
- **String methods** — splitting a sentence into words with `split()`, then rejoining them with
  `"-".join()`.
- **Loops** — the same list iterated two ways: a `while` loop driven by a counter and `len()`, and
  a `for` loop that reads each item directly.
- **`filter()` with a lambda** — selecting only the names that contain the letter `"e"`.
- **List comprehension** — building a new list of uppercased names in a single expression.
- **`range()`** — a `for` loop over `range(5)` to print a simple number sequence.

## Running it

```bash
python main.py
```
