# Coffee Order

'make_coffee' returns a coffee order in a dictionary.

- *extras collects extra items, like milk, in a tuple.
- **options collects named options, like size, in a dictionary.

Pro: We can add more extras and options easily.
Con: The function does not check whether they are valid.

Run the tests: 'python test_coffee.py'
Training file used: 'coffee.py'
